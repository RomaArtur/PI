# Kit Visual do Sistema

Este material foi pensado para explicar o projeto de forma simples, visual e rapida.

## Arquivos principais

- `docs/apresentacao.html`: pagina pronta para apresentar o sistema
- `docs/guia-leigo.md`: resumo em linguagem simples
- `docs/assets/visao-geral-sistema.svg`: fluxo do sistema
- `docs/assets/arvore-projeto.svg`: estrutura do projeto
- `docs/assets/mapa-postman.svg`: visao da collection do Postman

## Como usar

1. Abra `docs/apresentacao.html` no navegador.
2. Use os SVGs em slide, PDF ou WhatsApp quando quiser explicar o sistema.
3. Se quiser PNG, abra o SVG no navegador e exporte por captura ou impressao virtual.

## Publico ideal

- cliente
- professor
- avaliador
- pessoa leiga
- colega de equipe que ainda nao conhece o projeto
